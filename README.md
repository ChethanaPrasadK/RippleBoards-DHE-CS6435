# RippleBoards: Modeling the Interaction Structure of SDOH to Reduce Premature Mortality in Low-Income U.S. Census Tracts
Premature mortality among low-income Americans is one of the most preventable health inequities in US. Adults below poverty level experience nearly twice the premature mortality rate of higher-income populations. No existing tool simulates synergistic effects of stacking multiple SDOH. RippleBoards tract-level simulation engine enables users to select locations \& view projected mortality with confidence intervals.
